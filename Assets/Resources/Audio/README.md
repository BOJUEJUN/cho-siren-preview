# 背景音乐替换说明

把音频文件放到本目录，命名为 **`bgm`**，扩展名可以是 `.mp3` / `.ogg` / `.wav`：

```
Assets/Resources/Audio/bgm.mp3
```

游戏启动时 `GameAudio.LoadSoundtrackClip()` 会自动加载它并循环播放。

- **放进来就生效**，不需要改代码，也不需要改 Unity 场景。
- **没有文件时**，回退到代码合成的循环音（现状），不会报错。
- 音量沿用设置页的音乐开关，默认输出音量 0.18。
- 建议：循环无缝、时长 60–180 秒、码率 ≤192kbps，避免包体过大。

> WebGL 构建会把这里的文件一起打进包体，替换前注意文件大小。
