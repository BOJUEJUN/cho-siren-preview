## 三敌同屏

- 只有 1-2、1-8、1-13、1-18、2-2、2-8、2-13、2-18（`MaxOnStage: 3`）。其他关同屏仍最多 2 只（`BattleSimulator.MinionSlots`），首领关不用。
- 舞台是 1.5 个屏幕宽，三只怪排一排，每只和两怪关一样大（半屏宽）。镜头 = 敌人层水平平移 0 / ¼ / ½ 舞台宽（`TacticsBattlePanel.WideStage1111.cs`）：
  - 我方出手 → 移到目标；敌方出手 → 移到出手的怪；群攻 → 居中；点怪 → 移到它；活着的怪能同屏就同屏。
  - 背景放大 1.25 倍、半速跟着移（不露边）；屏幕外有怪时，那一侧显示青色箭头，点箭头看过去并锁定。
  - 名牌跟着怪移动；动作减弱选项打开时直接切换不滑动。
