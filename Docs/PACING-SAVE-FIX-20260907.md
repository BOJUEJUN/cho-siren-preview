# 第一章战斗节奏与清档修复（2026-09-07）

## 本次决定

用户先要求诊断秒杀和清档后已有通关记录，随后要求落实约一分钟战斗、按关区分小怪/精英/Boss，并允许生成敌人素材。保留已接受的固定关卡和“开始演出→章节地图”，不恢复等级适配，不降低已有存档等级，不覆盖其他任务的 Live2D 工作。

对照资料为本次附件《CHO-SIREN幻域魅声 游戏企划书(2).pptx》第 9、12–20 页。以最新“一分钟左右”要求覆盖其中 20–55 秒和 60 秒封顶：生产关卡上限 90 秒、75 秒内可得速度星。没有最低时长锁血、强制等待或按当前队伍动态拉高敌人。

企划书的 5 秒/回合时长估算不能直接代入当前连续自动普攻；“差 1000 不能过”与“差 2341 可操作翻盘”也冲突。本批不照抄绝对战力差封锁，采用实际模拟校准。旧数据/回放仍保留默认 60 秒、45 秒速度星。

## 已定位问题

- 原清档按钮需要四秒内二次点击，但只有 Toast 提示；一次点击不清档。改为单独确认弹窗，明确不可撤销，取消不影响存档。
- 原大厅和档案的“等级 68”为写死的演示文字。系统没有制作人经验，改为真实“队均 n 级”，不伪装成制作人等级。
- 原新档底层可正确清除通关，新增测试明确证明 reset 后及两次重新加载后均只开放 1-1，1-1 至 1-10 全无星；保留旧 v1 迁移键也不会恢复旧关卡。
- 原关卡已经存在不同数量，但整批同时入场，且普通关仍展示同一张 Boss 图。增加按波激活、Boss 阶段增援和实际敌人立绘。
- 延迟敌人不可选、不可被伤害；首波清完不能直接结算。群攻目标固定为施法开始时的队列，不能跨波清屏。Boss 被秒杀也仍需清理剩余敌人。

## 第一章配置

建议队均按 1–10 级逐关增长，属性是固定内容，不跟着玩家当前等级变化。

1. 1-1：回声无人机、噪声幽影；三波，每波两只，共六只。
2. 1-2：三波各两只，调整幽影/无人机组合及固定强度。

4. 1-4：两只混合怪、两只无人机、两只幽影，三波共六只。
5. 1-5：Boss 加一名跟班；Boss 60% 生命时护盾并召唤两只，30% 狂暴，共四只。
6. 1-6：精英加一名幽影，清除后两名增援，共四只。
7. 1-7：三波各两只，混合怪组合，共六只。
8. 1-8：双无人机、双幽影、混合组，三波共六只。

10. 1-10：Boss 加两名跟班；60% 时两名增援，30% 狂暴，共五只。

本轮精英增援在首组清空后进场，并非企划书的战斗中途召唤；普通怪的集火/亡命冲锋和世界 Boss 完整机制也不宣称全部完成。下一轮应继续细化这些操作反馈，不再先做装饰 UI。
