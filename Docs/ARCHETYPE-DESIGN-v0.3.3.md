# 流派设计 · 打击感与特效点

版本：v0.3.3　日期：2026-09-08
本文档定义四个流派的**定位、打击感参数、特效挂点**，供美术与程序后续实现对照。本文只新增设计，不改变现有战斗数值。

代码对应：`Assets/Scripts/Systems/Tactics/RealtimeBattle.cs` 的 `CastRaceSkill()`、`CombatRace` 枚举。

---

## 一、四流派定位总览

| 流派 | 代码 | 定位 | 一句话手感 | 主色 |
|---|---|---|---|---|
| 魔族·恶魔 | `Demon` | 持续伤害 / 范围压制 | 越拖越痛，毒在敌人身上"发酵" | 紫绿 |
| 魅族 | `Charm` | 攻速 / 控制打断 | 又快又碎，连击黏住目标 | 粉金 |
| 海灵·人鱼 | `Mermaid` | 治疗 / 护盾续航 | 柔软、有呼吸感，奶盾铺开 | 青蓝 |
| 血精灵 | `BloodElf` | 斩杀 / 破甲集火 | 冷、精准，收割那一下要"脆" | 猩红 |

## 二、各流派详细设计

### 1. 魔族·恶魔（Demon）— 持续伤害

**机制现状**
- 小技能「毒蚀斩」：单体 110% + 2 层毒 + 迟缓 3 秒（普攻间隔 +35%）
- 大招「万毒噬体」：全体 160% + 禁疗 30%（持续 3 秒）
- 队长效果：每次普攻按骰型附加毒层（三条 3 层 / 四条 5 层 / 五条 8 层）

**打击感**
| 项 | 参数 | 说明 |
|---|---|---|
| 顿帧 | 45ms | 中毒类不该太"硬"，顿帧偏短 |
| 屏幕震动 | 弱（幅度 0.4，0.12s） | 范围技才给中等震动 |
| 音效层次 | 两层 | 挥击闷响 + 0.15s 后毒雾"嘶"声 |
| 弹字 | 紫色 | 毒伤单独弹字，与普攻橙色暴击区分 |

**特效挂点**
1. **前摇**：施法者脚下紫绿法阵，0.3s 展开
2. **命中瞬间**：目标身上炸开毒雾球（半径略大于单位），颜色 #7F77DD → #97C459 渐变
3. **持续**：中毒单位头顶悬浮 3 个小毒泡，随层数增加（上限 15 层只显示 3 簇）
4. **结算**：毒结算（每 4 秒）时目标整体闪一次紫光，不顿帧
5. **大招**：全屏紫色毒雾从中心扩散，禁疗目标头顶加"禁疗"图标

### 2. 魅族（Charm）— 攻速与控制

**机制现状**
- 小技能「狐影瞬击」：两段共 120%，自身攻速叠加 5%（上限 24 层）
- 大招「魅语迷心」：前排 175% + 眩晕 1.2 秒 + 封技 2 秒（首领控时减半）
- 队长效果：魅影追击，按连击数追加攻击

**打击感**
| 项 | 参数 | 说明 |
|---|---|---|
| 顿帧 | 70ms（两段各 35ms） | 分段顿帧制造"连击"节奏 |
| 屏幕震动 | 无 | 靠位移残影表现速度，不靠震动 |
| 残影 | 3 段，透明度 0.5/0.3/0.15 | 位移时留下狐影 |
| 音效 | 快速两连击，第二下音高 +2 半音 | 强化"连"的感觉 |

**特效挂点**
1. **前摇**：几乎无前摇（≤0.15s），速度感优先
2. **位移**：从起点到目标的粉色残影轨迹
3. **命中**：金色狐火花瓣向外飘散 6 片
4. **控制成功**：目标头顶金色锁链缠绕（控制色统一金色）
5. **攻速叠加**：角色周身环绕的小光点数量随层数增加（每 6 层加 1 个，最多 4 个）

### 3. 海灵·人鱼（Mermaid）— 治疗与护盾

**机制现状**
- 小技能「汐愈微光」：全队净化 1 个负面 + 恢复 8%
- 大招「深海佑域」：全队 18% 护盾 + 减伤 15%（4 秒）+ 免疫眩晕 2 秒
- 队长效果：护盾加成 + 精准重投（可保留指定骰）

**打击感**
| 项 | 参数 | 说明 |
|---|---|---|
| 顿帧 | 0ms | 治疗/护盾不顿帧，保持流畅 |
| 屏幕震动 | 无 | 改为屏幕边缘泛青光 |
| 音效 | 上行琶音（3 音），混响重 | "水感"来源 |
| 弹字 | 绿色（治疗）/ 蓝色（护盾） | 严格区分，不要混用 |

**特效挂点**
1. **前摇**：施法者双手合拢，脚下水面涟漪扩散
2. **治疗瞬间**：目标身上绿色光点上升（速度慢，0.6s）
3. **护盾**：目标外围蓝色六边形水膜，随时间轻微波动
4. **净化**：负面图标被打碎成水花（每个被净化的状态一次）
5. **大招**：全队脚下同时升起水柱，屏幕边缘 0.3s 青蓝色渐变

### 4. 血精灵（BloodElf）— 斩杀与破甲

**机制现状**
- 小技能「血刃穿刺」：单体 115% + 无视 15% 防御 + 破甲 30%（4 秒，供全队集火）
- 大招「猩红处决」：目标生命低于 35% 时 200% 伤害，击杀后增攻 10%
- 队长效果：穿甲（按骰型 200–500‰）+ 收割（目标低于 30% 血时伤害 ×1.25）

**打击感**
| 项 | 参数 | 说明 |
|---|---|---|
| 顿帧 | 90ms（斩杀时 140ms） | 全流派最长，突出"处决" |
| 屏幕震动 | 中（幅度 0.8，0.15s） | 斩杀瞬间加强到 1.2 |
| 音效 | 金属穿刺高音 + 低频收尾 | 冰冷、锋利 |
| 镜头 | 斩杀时轻微推近（1.05 倍，0.2s 回弹） | 仅大招斩杀触发 |

**特效挂点**
1. **前摇**：角色后仰蓄势 0.25s，武器染红
2. **命中**：一道细长红色斩击线穿过目标（不是大范围爆炸）
3. **破甲**：目标身上出现裂纹纹理，紫色描边（破甲色统一紫色）
4. **斩杀**：目标碎裂成红色晶片，屏幕一帧黑闪（0.05s）
5. **击杀增益**：角色武器红光持续 3 秒（对应 `AttackBuffUntil`）

## 三、通用打击感基线

所有流派共用，差异见上表：

| 元素 | 标准 |
|---|---|
| 顿帧总时长 | 普攻 30ms，小技能 45–70ms，大招 80–140ms |
| 2 倍速时 | 顿帧时长减半，避免拖沓 |
| 暂停时 | 不播放任何顿帧与动画 |
| 弹字颜色 | 攻击青 / 受击红 / 暴击橙 / 治疗绿 / 护盾守护蓝 / 控制金 / 毒破甲紫 |
| 弹字数量上限 | 同屏 12 个，超出合并为"×N" |
