## 一、通过率怎么算的

- 用游戏里真正的回合制战斗，默认队伍（星璃当队长 + 绯音 + 雾白 + 夜莺），**开「自动」**（自动放大招、自动重投），同一批固定随机种子打几百局，算赢的比例。
- 「有装备」= 开局送的 3 件饰品 + 前面每关首通送的饰品，用「快捷穿戴」穿好。
- 「手动不操作」= 开手动但不点大招、不重投。
- 「骰子加成」= 正常玩法（骰子 + 队长被动，自动）的通过率 − 「骰子完全无效」（牌型一律按高点、没有队长被动、不能重投）的通过率。
- 1-1 的通过率指**重打**（第一次打 1-1 有新手保底，见第四节）。

## 三、骰子与队长（11-01 晚，你说「骰子加成你看着来吧」之后）

**目标**：骰子（含队长被动）让通过率多出约 10%，四个种族当队长差不多强。

**改前的问题**：6 颗骰子几乎每把都有对子/两对，而这些低牌型就已经给队长被动（魅族每次普攻多追打一下、恶魔挂毒…）和攻击加成，结果「完全没有骰子」时 1-1 只剩 25%、1-4 只剩 4%；魅璃当队长 1-5 能过 65%，其他三个队长 0~37%。

**改了什么**

| 项目 | 以前 | 现在 |
|---|---|---|
| 牌型攻击加成 | 从一对就开始：一对 +3.3%、两对 +6.7%、三条 +10%、葫芦 +15%… | **一对、两对不加**；三条 +3.3%、顺子 +5%、葫芦 +8.3%、四条 +13.3%、五条 +18.3% |
| 重投「热度」 | 每次没变差的重投 +2.5% | +1% |
| 牌型加快大招充能 | 从一对就开始，最多 +30% | 两对及以下不加，最多 +30% |
| 牌型目标达成后的「队长演出」 | 追打 150% + 30 点大招能量 | 追打 90% + 15 点 |
| 魅族队长「狐舞连斩」 | 一对就追击 1 次，葫芦 3 次，追击伤害 85% | **三条起**才追击（三条/葫芦 1 次，四条/五条 2 次），追击伤害 50% |
| 恶魔队长 挂毒 | 一对 1 层、两对 2 层…五条 6 层 | **三条起**：三条/葫芦 2 层，四条 3 层，五条 4 层 |
| 血精灵队长 破甲 | 三条起 15%~40% | 不变 |
| 人鱼队长「深海壁垒」 | 只在骰子变化时给一次护盾（一场 1~3 次） | **每回合开始**给全队补一层护盾：基础 2% 最大生命 + 牌型（三条 4%、顺子 3%、葫芦 5%、四条 7%、五条 10%） |

重投规则（每次最多 2 颗、不选 = 全部重投、每场最多 3 次）没动。

**结果（自动，400 局）**

| | 正常 | 骰子完全无效 | 骰子加成 |
|---|---|---|---|
| 1-1（重打） | 59.5% | 52.5% | +7 |
| 1-2 | 59.0% | 46.3% | +13 |
| 1-3 | 60.3% | 48.5% | +12 |
| 1-4 | 60.8% | 52.0% | +9 |
| **1-1~1-4 平均** | | | **约 +10** |

（游戏内测试用 200 局复核：+5 / +10.5 / +10 / +6，平均约 +8。）BOSS 关骰子更重要（1-5 约 +22，1-10 约 +32）：BOSS 关的胜负曲线很陡，一点点伤害差就会拉开通过率。

**四个队长（同样等级 + 装备，1-5 小 BOSS）**：魅族 星璃 63% · 恶魔 绯音 70% · 人鱼 雾白 72% · 血精灵 夜莺 61%（以前 65% / 37% / 0% / 5%）。其他关见完整报告：1-10 是 60 / 72 / 52 / 46%，2-5 是 66 / 46 / 61 / 54%，2-10 是 60 / 45 / 50 / 70%，后面几个 BOSS 关还有 15~20 个点的差距。

## 四、新手保底（你说「第一关可以简单点」）

- 已经**默认打开**：新号在第一次通关 1-1 之前，1-1 的敌人血量和攻击都 ×0.85（和「简单」难度一样），1 级不训练、自动打约 **95%** 能过（手动不点大招也有 90%）。
- 奖励、星级、显示的难度都还是「普通」，玩家感觉不到是降了难度。
- 通关一次以后，重打 1-1 恢复正常（约 60%）；只影响 1-1，不影响其他关。
- **1-2~1-4 对新手的情况**（不改目标，只给建议）：完全不训练的话每关约 60%，3 关里至少有一关「连输两次」的概率约 41%，「连输三次」约 18%；如果是手动又不点大招，1-2 只有 26%（连输两次 55%）。只要先花开局的星光币把 4 个人练到 3 级（共 432 星光币），1-2~1-4 就到 77~85%；练到 4 级（共 700）到 86~95%。
  - **建议**：第一次打输 1-2~1-4 时，结算页直接提示「先训练到 3 级再来」并给一个去训练的按钮；或者引导在 1-1 之后教一次训练。这两条属于引导/界面，这次没有改。

## 五、怪变强了什么

**所有 BOSS（每章第 5 关小 BOSS、第 10 关大 BOSS）**
- 每回合出手 **2 次**。
- 平时出手是「碎音横扫」——**打全队**。
- 每出手 3 次放一个大招，**提前一回合预警**（BOSS 头顶写「蓄力 · 群体禁魔·全队封技」，提示条写「魅声女王 蓄力「…」→ 全队」）。
- 大招轮换：
  - 小 BOSS：魅声爆鸣（全体重击）→ **群体禁魔** → 爆鸣 → 爆鸣
  - 大 BOSS：爆鸣 → **群体禁魔** → **蚀心侵染**（全体 + 禁疗 + 中毒）→ 爆鸣
  - 血量 30% 以下：换成终演震荡（更重的全体），大 BOSS 禁魔更频繁，攻击 ×1.5
- **群体禁魔**：全队被封印 2 回合，不能放技能和大招（普攻照打）。每个人身上会出现「封印」字样、心锁锁链和「封印 N 回合」图标。
- 原来的阶段机制保留：60% 血开护盾 + 召唤小怪（大 BOSS 会召唤精英狂响幻蚀歌姬），30% 血狂暴。
- 小 BOSS 攻击力在同关小怪基础上再 ×1.25。
- 怎么破：魅璃大招能把正在蓄力的 BOSS 封住，那个大招就放不出来；雾白小技能能解封印；「应急守护」能挡一下。

## 八、装备

- 一件饰品对战力的提升**最多约 5%**（实测最高 4.7%）：每项属性最多 +4.5%，强化每级 +0.5%，封顶不变。
- 4 个格子穿满大约 +10%~15%。

## 九、钱：不刷图不够花

训练费按 PPT 原公式（1→2 级 50，每级贵 15%）没动。关卡给的钱改成越往后越多（第一章 150 → 800，第二章 820 → 1800，BOSS 关多）。

| 想打 | 要练到 | 开局 + 之前首通能拿到 | 全队练到这个等级要花 | 还差 |
|---|---|---|---|---|
| 1-5 | 10 级 | 1,890 | 3,376 | **1,486**（≈ 刷 8 次 1-4） |
| 1-10 | 16 级 | 4,110 | 9,544 | **5,434**（≈ 刷 11 次 1-9） |
| 2-5 | 20 级 | 8,310 | 17,676 | **9,366**（≈ 刷 11 次 2-4） |
| 2-10 | 24 级 | 14,530 | 31,900 | **17,370**（≈ 刷 14 次 2-9） |

补钱的办法：刷图（3 星后能扫荡）、每日任务（约 1,100/天）、挂机（150/小时，最多 8 小时）、舞台演出（160/次）、商店「100 星钻换 2,000 星光币」（花钱买游戏币的入口；没接真实支付）。

为了让「钱不够花」成立，同时下调了：挂机 900/小时 → 150/小时（封顶 12 → 8 小时）；每日任务星光币 2,900 → 1,100/天；舞台演出 520 → 160/次。
