## 本批实际变化

- 生产关卡在 GameModel 创建时即启用实时规则，UI 和离线模拟使用同一个状态机；旧回合 API 只保留给无 EncounterType 的历史数据/回放测试。
- 第一章普通关为1、2、4、7、8，精英关为3、6、9，首领关为5、10。出场数分别2、3、4、3、4、5、4、4、6、6；精英/首领有对应主敌和杂兵。重投整场额度普通2、精英3、首领4，世界类型支持5但尚无世界首领入口。
- 普通关不再假装三阶段首领。精英每8秒硬化2秒，实际减伤50%；首领按其自身生命60%进入护盾阶段（15%最大生命），30%进入狂暴（攻击+50%、大招转全体）。致命伤不通过阶段护盾复活。未完成企划的中途召唤和世界首领光环，不冒充已覆盖。
- 所有正式成员使用相应种族基础值：魅族280/40/6/1.4，恶魔350/45/8/1.0，人鱼420/32/10/0.9，血精灵320/50/7/1.1（生命/攻击/防御/速度）。升级分别按1.085/1.065/1.05复利，取整后再加装备；训练用向上取整的50×1.15^(等级−1)，档案与实际扣费同源。
- 只有新建存档从全员1级起步；旧序列化档案、ID、等级、余额、已签约/编队和关卡进度保留。旧68级角色没有被降回1级；在新公式下属性会重新计算，不能声称保留原数值。旧高等级仍可快速碾压第一章，这不是新手节奏证据。
- 技能档案改用实际种族双主动技能名称及效果；不再显示旧高音穿刺/终场合唱却释放另一技能。毒、封技、硬化、减伤与护盾有紧凑状态提示；结算卡及奖励区改为不透明底，避免透出背后按钮和文字。
