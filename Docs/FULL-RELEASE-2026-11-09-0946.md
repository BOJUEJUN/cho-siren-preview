# 0.9.46 全量发布 · 2026-11-09

内容：
- 创意工坊重新设计：只保留 换装 和 炫彩。
  - 炫彩有 7 种配色：原色、冰蓝、樱粉、暗夜、鎏金、翡翠、赤焰。
  - 新着色器 `UIChroma1109` 把衣服和头发等鲜艳部分换成目标色相，皮肤不变。待机视频（`UIStackedAlpha`）也用同样的换色。
  - 选好的配色存在 `WorkshopLook1104.Chroma`。
  - 去掉了 背景、转身、半身 / 全身切换，固定全身视角。
  - 底部两个工具改成平分整条的宽按钮：深色底、青色边框；选中时整块填满青色。
- 库存：
  - 新增 材料 分类：饰品页只显示持有的材料，图鉴页显示全部。
  - 材料按稀有度排序：声核 > 生魂 > 其他；选“最近获得”时按数量多少排。
  - 底部导航“饰品”改名“库存”。
- 练习室：
  - 用舞台打光标出主唱。
  - 平时待机呼吸，开始练习后才唱跳。
  - 修复减弱动画下看不到成员、LIVE 标题和时间码重叠。
- 右上角货币栏放大。
- 测试：`InventoryReview1028Tests` 开始前先清掉之前测试留下的画布（之前偶尔误读别的测试的格子）。
