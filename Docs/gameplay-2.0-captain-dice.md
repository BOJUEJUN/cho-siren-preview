# 战斗玩法 2.0：队长风格与骰子联动

> 版本定位：2.0 设计规格。本文描述下一阶段玩法，不代表当前版本已经全部实现。

## 1. 设计结论

战斗界面中的四个形象不是阵营、属性派系或职业克制，而是四类“队长风格”。队长决定本轮如何使用骰子，以及当前出手成员获得什么强化。

- 每局开始前选择一名初始队长。
- 每轮开始时显示当前队长，并允许玩家在规定条件下换队长。
- 骰子结算强化的是“当前出手成员”，不默认给全队永久加成。
- 队长效果改变骰子的用途，但不替代角色技能与目标选择。
- 队伍成长后，玩家通过更灵活地换队长、增加出战人数和形成技能配合来提高上限。

这样可以让同一套成员在不同队长下形成不同打法，同时避免再增加一套难以理解的派系克制。

## 2. 与 1.0 战斗的衔接

当前 1.0 已落地的基础规则继续保留：

- 每次玩家行动投掷五颗骰子。
- 可点击骰子进行保留，每回合最多重投两次未保留骰子。
- 五骰会识别八类骰型，并生成对应的伤害或效果倍率。
- 骰子能量达到 100 时，可消耗全部能量进行一次全重投。
- Boss 战按生命比例表现为三个阶段。
- 玩家仍需选择当前成员的技能与合法目标；自动模式可完成同样的合法行动。

2.0 不重写以上规则，而是在“骰型已经判定、技能即将释放”之间加入队长修正：

```text
当前成员行动
→ 五骰投掷、保留与重投
→ 判定骰型和基础倍率
→ 当前队长修正骰子用途
→ 选择技能与目标
→ 当前成员释放强化后的技能
→ 累积能量并进入下一行动
```

## 3. 四类队长风格

四类队长都应同时提供一个常驻规则和一个有条件触发的骰型强化。名称为原创工作名，可在美术定稿时调整。

### 3.1 迷心指挥

定位：魅惑、群体压制、低直接伤害。

- 伤害型技能可以扩散到额外敌人，但直接伤害倍率低于强攻型队长。
- 高价值骰型优先强化魅惑、行动延后、命中下降等控制效果。
- 面对多目标关卡收益高，面对单体 Boss 时依赖阶段机制和控制抗性平衡。
- 不允许“低伤害”被群体目标数反向放大成最高单体输出。

### 3.2 干扰指挥

定位：给敌方施加负面状态，为后续成员创造窗口。

- 当前成员命中后可附加攻击降低、防御降低、受疗下降或易伤中的一种。
- 骰型越完整，负面状态的强度、持续轮数或影响目标数越高。
- 重复施加遵循明确的刷新或叠加上限，不能无限叠层。
- 适合安排在高速成员或队伍行动序列前段。

### 3.3 变奏指挥

定位：操控骰子、提高成型稳定性。

- 可增加一次条件重投、锁定一颗骰子，或将一颗骰子调整到相邻点数。
- 强化应改变决策空间，而不是自动保证最高倍率骰型。
- 与 1.0 的“两次普通重投”和“100 能量全重投”分别计数、分别展示。
- 自动模式必须使用与手动模式相同的次数和能量约束。

### 3.4 守望指挥

定位：攻击与回血之间切换，维持队伍节奏。

- 当前成员使用攻击技能时获得适中的攻击强化。
- 当前成员使用治疗或护盾技能时，提高回复量，或为生命最低成员提供小额补充恢复。
- 同一次行动只能选择攻击方向或恢复方向，避免同时获得完整的两套收益。
- 适合长线 Boss 战与低练度队伍，但爆发上限低于专门的输出组合。

## 4. 每局与每轮的队长选择

### 4.1 开局选择

进入战斗前展示四类队长风格、核心效果和推荐场景。玩家选择一名作为首轮队长；自动编队可按敌人数、队伍技能和关卡标签给出推荐，但不能替玩家永久锁定。

### 4.2 轮间换队长

队长切换只发生在轮次边界，不在单次技能动画中打断流程。建议初版采用以下规则：

- 每轮开始时可保留当前队长或选择另一名队长。
- 每局拥有有限的免费切换次数，额外次数可由队伍成长解锁。
- 切换后从下一名出手成员开始生效，不追溯已经完成的行动。
- Boss 进入新阶段时必须再次展示当前队长和切换机会，但不强制更换。

## 5. 骰子与当前成员的结算原则

- 骰型倍率首先作用于当前成员本次选择的技能。
- 队长修正必须记录来源，伤害预览与实际结算使用同一组参数。
- 当前成员倒下或行动被取消时，不应无提示地消耗队长次数或骰子资源。
- 群体技能按同一骰型快照结算，不为每个目标重新掷骰。
- 治疗、护盾、负面状态等非直接伤害技能也可读取骰型，但各自使用独立的效果倍率上限。
- 100 能量全重投后，重新判定骰型，再由当前队长进行修正。
- Boss 三阶段可调整控制抗性、负面状态上限或队长切换价值，但不得暗改骰子点数概率。

## 6. 成长与队伍上限

2.0 的成长重点不是简单堆数值，而是扩大可组合空间：

1. 初期队伍人数少、免费换队长次数少，玩家容易理解单一打法。
2. 成员成长后解锁更多技能与行动顺序搭配，让不同队长能服务不同成员。
3. 队伍扩充后，同一轮可以安排“负面状态铺垫 → 输出成员爆发 → 回复成员收尾”。
4. 后期通过增加出战人数上限、队长切换次数和队长专精分支提高策略上限。

扩充人数必须同时检查单局时长。目标仍为约 60 秒；人数增加后应通过动作合并、动画加速、自动模式和敌方行动压缩控制节奏，而不是无限拉长回合。

## 7. 后续数据字段

建议采用数据驱动，不把四类效果写死在界面代码中。

### 7.1 队长定义 `CaptainStyleDefinition`

- `Id`：稳定标识。
- `DisplayName`：中文显示名。
- `Description`：短说明。
- `PortraitResourcePath`：队长形象资源路径。
- `StyleType`：迷心、干扰、变奏、守望。
- `PassiveEffectId`：常驻效果。
- `DiceModifierId`：骰型修正规则。
- `PreferredPatterns`：重点强化的骰型列表。
- `DirectDamagePermille`：直接伤害修正。
- `EffectPowerPermille`：治疗、护盾或状态强度修正。
- `TargetExpansionCount`：额外目标数。
- `StatusId`、`StatusDuration`、`StatusStackLimit`：负面状态配置。
- `ExtraRerolls`：额外条件重投次数。
- `DiceAdjustCount`：允许调整的骰子数量。
- `SwitchCost`：切换消耗。
- `UnlockConditionId`：解锁条件。

### 7.2 战斗规则 `CaptainBattleRules`

- `InitialCaptainSelectionRequired`：是否强制开局选择。
- `SwitchTiming`：切换时点，初版固定为轮次边界。
- `FreeSwitchesPerBattle`：每局免费切换次数。
- `SwitchesGrantedByProgression`：成长追加次数。
- `MaxPartySize`：当前出战人数上限。
- `TargetBattleSeconds`：目标战斗时长，默认 60。
- `BossPhaseSwitchPrompt`：Boss 换阶段是否弹出队长提示。
- `AutoCaptainPolicyId`：自动模式选择策略。

### 7.3 运行时状态 `CaptainBattleState`

- `CurrentCaptainId`：当前队长。
- `PendingCaptainId`：下一轮待切换队长。
- `SwitchesRemaining`：剩余切换次数。
- `RoundSelected`：本轮是否已经确认。
- `ActingUnitId`：本次受骰子强化的成员。
- `DiceSnapshot`：五骰点数、保留状态、骰型和基础倍率。
- `AppliedModifiers`：本次结算采用的队长修正明细。

### 7.4 战报字段

- `CaptainSelected`：开局或轮间选择。
- `CaptainSwitched`：切换前后队长及消耗。
- `DiceModified`：队长对骰子的调整。
- `CaptainEffectApplied`：效果来源、目标、倍率和持续轮数。

## 8. 界面要求

- 四个队长入口必须写成“风格”或“队长”，不能表现为互相克制的派系。
- 当前队长、剩余切换次数和生效对象始终可见，但不遮挡中央角色舞台。
- 五骰、保留状态、剩余两次普通重投、能量全重投仍是主要交互区。
- 伤害或治疗预览需要分别显示“骰型倍率”和“队长修正”，避免玩家不知道数值来源。
- 自动模式开启时，界面仍应短暂展示队长选择、骰型和最终修正结果。
- 所有正式界面只使用中文。

## 9. 验收标准

### 9.1 规则验收

- 四个形象在数据和界面中均被识别为队长风格，没有派系克制字段或文案。
- 开局可以选择初始队长，轮次边界可以在次数允许时更换。
- 切换从下一名行动成员开始生效，已经结算的行动不受影响。
- 骰型与队长修正只强化当前出手成员的本次技能，除非配置明确指定群体效果。
- 四类方向均可独立验证：魅惑群伤低直伤、敌方负面状态、骰子重投或调整、攻击与回血切换。
- 1.0 的五骰保留、两次重投、八骰型倍率、100 能量全重投全部继续可用。
- Boss 三阶段切换不丢失当前队长、骰子能量或战斗状态。

### 9.2 数值与一致性验收

- 预览数值与实际伤害、治疗、护盾及状态持续时间一致。
- 手动模式和自动模式消耗相同的重投次数、能量与队长切换次数。
- 魅惑群伤队长在同练度单体测试中不超过专门输出组合的单体伤害上限。
- 负面状态达到叠加上限后不会继续增长，刷新规则与界面提示一致。
- 全重投只扣除一次 100 能量，并清空原保留状态后重新判定骰型。

### 9.3 体验验收

- 新玩家能在一次开局选择中理解四种队长的差异，不需要先学习派系关系。
- 普通关卡和 Boss 战的中位完成时间接近 60 秒，扩充队伍后也不出现明显失控。
- 关键选择均可通过键鼠或触控完成；竖屏 720×1536 下无按钮重叠或文字溢出。
- 战报可以完整还原队长选择、骰子结果、修正来源与最终结算。

## 10. 推荐实施顺序

1. 增加队长定义、战斗状态和战报字段，不改现有骰子概率。
2. 实现开局选择与轮间切换，并先接入一类队长完成端到端验证。
3. 接入其余三类效果，统一预览与实际结算管线。
4. 补自动模式策略、Boss 阶段提示和队伍成长解锁。
5. 完成 60 秒时长、叠加上限、竖屏布局和战报回放验收。
