## 建议：主入口团练，个人等级保留

1. 大厅练习室默认展示当前出战四人；一次点击共同排练，四人各升一级。已满级成员显示满级，不收费。不同初始等级保留，避免修改既有存档和成员成长体系。
2. 唯一主按钮“全团练习”，旁边显示参与人数与金币总费用。费用先按现有四人的单练报价求和，不引入新货币、额外团等级或免费四倍成长。
3. 金币不够整次费用时不能开始；开始前重新核对成员、等级、金币，一次结算并保存，不能扣完一半后失败。任务计数按成功练习动作一次，成员好感按各自训练结果。
4. 共用约 1.4 秒排练演出，四人有合拍动作；结算只显示四个“原等级 → 新等级”和团队战力变化。原版单练移到成员详情，方便补练新成员。
5. 这里的“集体”指当前出战队伍，不自动花钱升级整个角色库。用户如想所有角色统一等级，应另作完整养成设计后再改。

## 关卡页三个视觉方向

- A 城市巡演：城市屋顶/场馆组成清楚的地图，细路线串联节点，底部统一黑色面板；推荐，保留探索感。
- B 黑胶曲目：圆形黑胶与弧形曲目节点，黑紫底、青色当前曲目，与大厅底盘呼应。
- C 演出歌单：演出海报加简洁关卡歌单，只高亮当前一行，信息最清晰。

共同约束：黑紫青主色、少量粉色；保留不规则纸边与网点语言，但减少发光碎片和重复电光框。文字和关卡点击区独立布局，不把整屏概念图拉伸当 UI。上方安全区、固定底部操作区，中间地图/列表可滚动。先确认方案，再拆图与真实 UI 接入。
