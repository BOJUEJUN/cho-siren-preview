# 2026-09-08：统一选人、队长任命与累计骰子

发布前基线：Web 422a642，Unity 4f381c2。保留旧版构建与存档，不重置玩家数据。

## 本轮实现

- 队长、编队、装备管理与替换对象共用头像选人面板。默认已拥有，可切全部、搜名称、翻页。未签约只能查看档案；返回保留筛选和页码。
- 更换队长先选人、查看效果，再任命。在队成员任命不移除其他队员；待命成员需要确认替换旧队长，等级、装备和其他队员保留。
- 档案单独显示四类队长指挥效果；未签约禁用任命。
- 骰子伤害加成按加法累计：开局 (旧骰型倍率−1)/4，重投同式但最低 +5%。累计最多 +100%（×2），不因新骰型较弱而减少。附加追击/护盾/毒/穿甲仍按当前骰型和指挥者，不叠乘累计收益。
- 普通/精英/Boss 的既有重投预算保留。换波、队长倒下不重置累计；新战斗重置。自动投掷不在高倍率骰型提前停止，会投到预算耗尽或累计封顶。
- 第一章十关 120 秒硬时限、100 秒三星时限；末 20 秒红色倒计时与判负提示，暂停不计时，倍速推进战斗时钟。暂停面板内附完整规则。
- 固定敌方生命较上一版约 +10%，攻击、防御和波次保持。不给高等级玩家强制延时。
