# v0.3.4 需求页：深入交流（赵金反馈 #12）

日期：2026-09-08。来源：赵金 2026-09-08 十二项反馈第 12 条「深入交流（下版）」；
v0.3.3 交接已将本功能列为下一版建议项。本文是 v0.3.4 的实现范围与验收标准，先写需求再动手。

## 范围

在成员档案页为好感度达到「羁绊」档（≥80）的已签约成员解锁「深入交流」玩法：
与成员进行一次专属对话，消耗少量星光币，获得当日一次的好感度提升与专属文案。

**明确不在本版范围**（防止无限扩张）：
- 不做剧情树、多结局、选项分支对话；
- 不做语音、Live2D 动画或新立绘（复用现有立绘资源）；
- 不改战斗、掉落、经济其他数值。

## 功能定义

| 项 | 值 | 说明 |
| --- | --- | --- |
| 解锁门槛 | 好感度 ≥ 80（羁绊档） | 与 `GameModel.AffectionTierName` 的羁绊阈值一致，不另设第二套阈值 |
| 消耗 | 星光币 200 | 与训练同货币；签约星钻、关卡体力均不涉及 |
| 次数 | 每位成员每日 1 次 | 以本机日历日（`DateKey(Today)`，与签到同口径）为界 |
| 收益 | 好感度 +6（上限 100） | 比单次训练（+3）高，作为羁绊档专属奖励 |
| 入口 | 成员档案页新增按钮 | 未达门槛显示「好感度80解锁」；已用显示「今日已交流」；星光币不足显示「星光币不足」 |
| 表现 | 专属对话弹窗 | 复用成员立绘 + 档位专属文案池随机一条 + 好感度变化提示 |

## 文案池

- 至少 8 条羁绊档文案，通用 + 成员姓名插值；不按种族/职业写专属分支（本版从简，后续可扩）。
- 文案须符合女团偶像养成题材、健康向，无敏感内容。

## 存档兼容

- 新字段：`GameSave.MemberDeepTalkDate`（`List<string>`，按成员索引存最近交流日期 key）。
- 旧存档（无该字段）加载后正常游戏：字段缺省为空列表，视为从未交流，不触发迁移或清档。
- 不修改既有字段含义；`SchemaVersion` 不变（新增可缺省字段不需要升版）。

## 验收标准

1. EditMode 回归（新增 `DeepTalkV034Tests.cs`）：
   - 好感度 <80 拒绝；≥80 成功；
   - 扣星光币不扣星钻；好感度 +6 且不超 100；
   - 同日第二次拒绝；跨日（nowProvider +1 天）恢复可用；
   - 旧存档（无新字段）加载后可正常深入交流；
   - 文案池非空且全部包含姓名占位替换结果。
2. 本机 WebGL 构建真实实玩（agent-browser 独立测试档案）：
   - 新号正常流程刷好感度至 80+（训练 +3/次，真实点击，不改存档）；
   - 档案页按钮从「好感度80解锁」变为可用；
   - 点击后弹对话、扣 200 星光币、好感度 +6；
   - 按钮变「今日已交流」且不可再点；
   - 刷新页面后好感度与当日已交流状态持久化。
3. 发布：测试全绿 → 构建 → 实玩 → Stage-WebGL 发布（保留 v0.3.3 回滚点）→ npm run check → 备份（bundle + web 归档 + SHA256 + 恢复验证）→ 推送 → 线上 release.json 与资源 200 验证。
4. 不动：玩家存档格式既有字段、旧版本标签、既有备份、BoxJob。
