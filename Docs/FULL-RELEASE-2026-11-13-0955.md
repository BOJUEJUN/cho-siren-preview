# 0.9.55 全量发布（2026-11-13）

少爷让接手 Claude 的未发布改动，全量发布。源码提交 `81ec7b3`，已推送 `origin/release/music-0.3.5-20260909`。

## 内容

- 幻纱、幻惑伶、凛音换新立绘，六段大招动画接入；幻纱两段、凛音三段按次随机播放。
- 幻惑伶、凛音加入大厅轮播，带待机动画及文字台词；两位的新台词尚无新增配音。
- 工坊衣橱：生成结果自动收纳、试穿、穿戴、删除，穿戴同步成员页、战斗和剧情；支持分部位换装，去掉炫彩。
- 游戏风下拉框、队名改名笔、功能骰入口位置与开放提示、播放器尺寸优化；大招镜头推近/拉远增强。
