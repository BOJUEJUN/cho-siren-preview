## Import settings

`Assets/Editor/EnemyArtImportProcessor.cs` applies only to PNG textures within `Assets/Resources/Art/Enemies/`:

- Sprite, single; input alpha retained and alpha-is-transparency enabled.
- Maximum texture dimension 1024, with no mipmaps and no CPU read/write copy.
- Bilinear filtering and clamp wrapping; no NPOT scaling.
- High-quality automatic platform compression, quality 80, with Crunch enabled for Standalone and WebGL to bound download size.

The 1024 limit downscales the 1536-pixel source height at import; source files remain full resolution. Unity selects a platform-compatible compressed format. Final imported size, on-device edge quality, build payload, and browser rendering must be checked in the main task's Unity/WebGL verification; source PNG size alone does not establish the deployed payload size.

No Unity process was launched by the asset-import subtask. Unity will generate the PNG/folder `.meta` files on import. Commit those generated metadata files with the assets after the main task's import.
