# v0.3.2 主动战术更新

## 设计

原来的12秒免费打断只在敌人施法时可点，容易变成等按钮亮。替换为两个固定名称、独立冷却的主动战术，施法与角色伤害仍使用战斗模拟器，UI不直接修改生命或状态。

- 破招突袭：150%攻击，12秒冷却；选中敌人为优先目标，无选择时优先施法者。平时可以直接进攻；成功打断额外眩晕1.2秒（首领0.6秒）、破甲30%持续4秒。免控与控后保护不被绕过。
- 应急守护：全队3秒减伤50%，18秒冷却。独立于既有护盾，不消耗或替换角色护盾；伤害结算统一减免。
- 实际指令施放者优先队长，队长眩晕/封技时由可行动队员接替；全员无法行动不扣冷却。暂停不释放、不计冷却；新战斗归零。
- 敌人头顶展示当前技能、目标和2秒读条，最后0.7秒变红。固定战术名称下方显示用途、冷却或破招时机。成功操作短暂反馈不被每帧提示立即覆盖。
- 保留120秒判负、骰子累计上限与原有关卡血量；本次不更改存档格式。
