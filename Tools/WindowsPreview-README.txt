CHO-SIREN《幻域魅声》Windows 预览版

打开方法：
1. 请先完整解压压缩包，不要直接在压缩软件里运行。
2. 保持所有文件和文件夹在同一目录中。
3. 双击 CHO-SIREN.exe 启动游戏。

操作说明：
- 使用鼠标点击顶部功能、首页四个舞台入口和底部导航；按钮悬停与按下会有反馈。
- “开始演出”进入节奏演出，“冒险剧本”进入第一章 1-1 至 1-10；十关按顺序真实解锁。
- 副本使用五枚骰子：选择保留、最多重投两次，再按牌型倍率发动成员技能；每场约 1 分钟。
- 音乐开关与音量统一在右上角“设置”中调整。
- 游戏进度保存在当前电脑中。

注意：
- 不要只复制 CHO-SIREN.exe；CHO-SIREN_Data、MonoBleedingEdge 和 DLL 文件都是运行所必需的。
- Windows 压缩包不会自动更新；收到新版后需要重新下载。
- CHO-SIREN.exe 和“开始游戏.cmd”只能运行成品，不能编辑工程。
- 在完整源码工作区中，可双击仓库根目录“打开CHO-SIREN编辑器.cmd”；Builds\Windows 内也会生成仅供源码工作区使用的“打开Unity编辑器.cmd”。
- 在线预览会保持同一个地址并自动切换为最新部署版本：
  https://bojuejun.github.io/cho-siren-preview/
